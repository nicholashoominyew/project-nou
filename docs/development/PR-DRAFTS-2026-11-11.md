## PR 1 — `fix/editor-undo-alignment-shortcuts` → `feature/workspace-tabs-pages-files`

**Title:** Fix window close and editor undo; add file drops, image resize, Notion-style sidebar and shortcuts

### What
- **Window close:** the X button did nothing because the app's close handler needs `core:window:allow-close` and `allow-destroy`. Added to `capabilities/default.json` with a test that fails if they go missing. *User-confirmed fixed in the real app.*
- **Undo:** React.StrictMode's dev remount destroyed the Yjs UndoManager, so Ctrl+Z failed in dev (production was fine). StrictMode removed, with a test.
- **Popovers:** icon picker, row menu and export menu close on outside click or Escape (`Dismissible.tsx`).
- **Shortcuts:** Ctrl+P prints (print styles added), Ctrl+Q opens Quick find, Ctrl+\ toggles the sidebar, Ctrl+N / Ctrl+W / Ctrl+Tab.
- **Files:** drop images, PDFs and any other file onto a page; new generic file block and `/file`; images resize by dragging the right edge; attachments are seamless (no grey card until hover or selection). New raw-bytes upload command; 20 MB cap; HTML is stored, never rendered.
- **Sidebar:** Notion-style tree with hover actions, context menu, inline rename, favorites (`set_page_favorite`), resizable and collapsible.
- **`NOU_PROFILE_DIR`:** lets the app run against a disposable profile folder. Unset behaviour is unchanged.

### Risk and compatibility
No schema change. A non-PDF named `.pdf` is now stored as a generic file instead of rejected.

### Verified
TypeScript clean; Vitest and Rust library tests pass on this branch's head. User reported the close fix, drops and sidebar as working in the real app before later changes. Print output and clipboard behaviour were not checked in a real window.

## PR 2 — `feature/databases` → `fix/editor-undo-alignment-shortcuts`

**Title:** Add inline databases: views, relations, rollups and Notion-style column menu (schema v4)

- **Properties:** text, number, select, multi-select, status, date, checkbox, URL, email, phone, place, created time, last edited time, relation (one- or two-way, kept in sync), rollup (computed in Rust).
- **Column menu and view settings:** rename, change type (only without data loss), filter (And/Or), sort, group, calculate, freeze, hide, wrap, resize, insert, duplicate, delete (soft), option editing; search; row menu (open, duplicate, delete); row side panel.
- **App shortcuts:** Ctrl+[ / ], Ctrl+1–9, Ctrl+Shift+T/L/U, zoom, Ctrl+/ list, Ctrl+D, `@` page link.
- Docs: `docs/development/DATABASES.md`, ADR-003, VERIFICATION.md entry.

**One-way schema upgrade.** A profile moved to v4 cannot be opened by builds without this migration (0.0.3 and earlier 0.0.4). A `schema-rollback` snapshot is taken first, as for v3. Rehearse on a **copy** of real data. v4 was amended several times on this branch before any real profile used it; a disposable profile made by an earlier commit will not match.
